# U-Script - تطبيق موبايل (APK)

التطبيق ده غلاف للمتصفح (WebView) بيفتح WebUI الرسيفر على طول.

## البناء (GitHub Actions - مجاني)
1. اعمل Repository جديد على github.com باسم uscript-app
2. اسحب فولدر المشروع كله (بعد فك الضغط) وارميه جوه صفحة الريبو - كل الملفات هتترفع بما فيها مجلد .github
3. افتح تاب Actions -> استنى البناء يخلص -> افتح الـ run -> حمّل U-Script-APK
4. ثبّت ملف app-debug.apk على موبايلك

## اول تشغيل
- التطبيق بيفتح http://192.168.1.42:8080 تلقائيا
- لو IP الرسيفر مختلف: من القايمة اختار "تغيير IP الرسيفر" واكتب IP الجديد
- لازم الموبايل والرسيفر على نفس الواي فاي
